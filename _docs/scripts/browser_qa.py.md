## Overview

This module provides a small set of utilities to run browser-based smoke tests against a built Arabic blog, with attention to narrow right-to-left (RTL) viewports. It includes a function to wait for the server to be available using urllib, a function that drives a Playwright-controlled browser to verify rendering at specific viewport sizes and directions, and a main entry point that ties those behaviors together for command-line invocation. The exported functions focus on availability checks and automated visual/functional verification rather than on test assertion frameworks or reporting.

The implementation depends on urllib for simple HTTP availability checks and on Playwright's synchronous API to launch and control a browser instance. The intended use is to ensure the built site serves content and that basic layout and interaction expectations are met when rendered in narrow RTL viewports commonly used for Arabic sites.

## Overview

This directory contains a focused set of scripts used to perform browser-based smoke testing of the built Arabic blog. At the root there is a single module, browser_qa.py, which implements utilities to launch and validate light-weight browser checks targeted at RTL rendering and narrow viewport behaviors. The scripts here are intended to be run against a completed build of the site rather than during the build process itself.

Because there are no subdirectories, the directory is intentionally minimal and purpose-driven: it provides an entry point for QA automation focused on RTL layout and narrow viewports for Arabic content. The contents are designed to integrate into a larger QA workflow by being invoked from CI or by a developer running manual smoke checks against a deployed or locally served build; the module's emphasis on narrow RTL viewports makes it especially useful for regression checks that validate text direction, layout mirroring, and responsive behavior on constrained widths.


### File Organization

All scripts live at the root of this directory in a single-file layout. This flat organization reflects the small, focused nature of the QA utilities—there is one module (browser_qa.py) that contains the available tools rather than spreading functionality across multiple files or subpackages.

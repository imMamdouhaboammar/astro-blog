# بلاي بوك ممدوح (Mamdouh's Playbooks) 📚

منصة معرفية عربية وبلاي بوكس مصوّرة للمفاهيم البرمجية والهندسية، وعلوم البيانات، والذكاء الاصطناعي — إعداد **ممدوح أبو عمّار**.

---

## ✨ المميزات الرئيسية

- **دعم كامل للغة العربية (RTL First):** تجربة قراءة وتصفح عربية مريحة مع خطوط الثمانية ومحاذاة دقيقة.
- **بلاي بوكس عملية ومصوّرة:** سلاسل متكاملة (مثل سلسلة PyMC Marketing ومفاهيم MMM والـ Adstock والـ Saturation).
- **تصميم Pixel Art متناسق:** شريط تنقل Pixel Navbar وأيقونات مخصصة وأزرار تفاعلية.
- **أداء عالي وسرعة فائقة:** مبني باستخدام Astro 4 وتوليد صفحات ثابتة (SSG) محسنة بالكامل.
- **بحث فوري:** بحث متقدم يدعم اللغة العربية بواسطة Fuse.js.
- **متوافق مع المعايير القياسية:** SEO متقدم، بطاقات Open Graph ديناميكية، بيانات منظمة JSON-LD، وخريطة موقع تلقائية وRSS feed.

---

## 🛠️ أدوات التطوير والتشغيل

المشروع يعتمد على **Bun** كمدير حزم وأداة تشغيل أساسية.

```bash
# تثبيت الاعتماديات
bun install --frozen-lockfile

# تشغيل خادم التطوير المحلي
bun dev

# فحص أنواع TypeScript وAstro
bunx astro check

# تشغيل الاختبارات السريعة
bun test

# بناء المشروع للإنتاج مع تحسين الأصول
bun run build

# تشغيل التحقق من سلامة البناء
python3 scripts/verify_integrated_blog.py
```
